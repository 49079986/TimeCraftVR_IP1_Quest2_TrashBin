# Open this folder in Unity

Add this folder in Unity Hub and open it with Unity **6000.3.24f1**:

`D:\UnityProjects\TimeCraftVR_IP1_Quest2_TrashBin`

Open scene:

`Assets/Scenes/TimeCraft_IP1_Editable_Prototype.unity`

No-headset test: select a media clip, press **G** to crumple it, then drag and flick it
into the red trash bin. Press **R** to restore recycled clips.

Quest 2: Trigger selects; hold Grip to crumple and hold; release Grip while moving your
hand to throw.
